# Mikrozement-Landingpage — Berisa Bau

Zielseite für die Google-Ads-Kampagne „Mikrozement". Reine statische Seite,
kein Backend: HTML, Bilder, drei kurze Hintergrundvideos.

**Diese Seite ist `noindex, nofollow`** und gehört nicht in Sitemaps oder
interne Verlinkungen — sie ist ausschließlich für bezahlten Anzeigen-Traffic.

Gepflegt wird sie im Hauptprojekt unter `berisabau-landingpage/mikrozement.html`;
hier liegt nur der veröffentlichte Stand.
